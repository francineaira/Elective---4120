## 🕊️ About the Activity

This activity focuses on creating a personal portfolio website using a website-building platform. It explores how digital tools can be used to develop an online space that presents personal information, skills, experiences, and creative elements through an organized and visually engaging design.

## 🌐 Activity Output

**Personal Portfolio Website**

The output is a one-page personal portfolio website created using **Base44**. It showcases personal information, skills, experiences, and creative elements while applying website design principles to establish a cohesive and user-friendly presentation.

## ✧ Skills and Concepts Applied

- **Website Development** – Using a website-building platform to create a functional personal portfolio.
- **Digital Design** – Applying visual elements to establish an organized and appealing website layout.
- **Personal Branding** – Presenting personal information and professional identity through a digital platform.
- **Content Organization** – Arranging information into sections for easier navigation and understanding.
- **Technology Integration** – Exploring how digital tools can simplify website creation and development.

## 🪷 Reflection

This activity provided an opportunity to explore website creation and the use of digital platforms in developing a personal online presence. Through creating a personal portfolio website, I gained a better understanding of how design, content organization, and technology work together to present information effectively.

It also allowed me to explore how a website can serve as a platform for showcasing personal skills, experiences, and creative work in an organized and accessible manner.
