## 💻 Skills and Concepts Applied

- **File Storage:** Understanding how Google Drive stores digital files.
- **File Organization:** Organizing files and folders for easier navigation and retrieval.
- **File Accessibility:** Accessing files across compatible devices.
- **File Sharing:** Sharing files and folders through links and access permissions.
- **Collaboration:** Using shared files to support teamwork and collaborative work.

This activity helped me understand the importance of digital file management in academic and professional settings.
