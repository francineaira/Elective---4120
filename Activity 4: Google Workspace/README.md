## 🕊️ About the Activity

This activity focuses on exploring the different tools and features available under Google Workspace, particularly Google Drive. It highlights how digital platforms can be used to store, organize, access, share, and collaborate on files, making digital file management more convenient and efficient.

<br>

## ✧ Activity Output

**Google Workspace – Google Drive**

The output demonstrates the use of Google Drive as a platform for managing digital files. Through this activity, I explored its features for storing and organizing files, accessing documents, sharing resources, and collaborating with others.

This activity provided an opportunity to understand how Google Drive can support academic tasks and improve the management of digital resources.

<br>

## ✧ Objectives

- Explore the different tools and features available under Google Workspace.
- Understand how Google Drive can be used to store and organize digital files.
- Demonstrate how files can be accessed and managed through Google Drive.
- Explore file-sharing features and access permissions.
- Recognize how Google Drive supports collaboration and productivity.

<br>

## ✧ Concepts and Skills Applied

- **Digital File Management** – Understanding how digital files can be stored and managed using Google Drive.
- **File Organization** – Arranging files and folders for easier navigation and retrieval.
- **Cloud Storage** – Exploring how files can be stored and accessed online.
- **File Sharing** – Using sharing links and access permissions to provide others with access to files.
- **Digital Collaboration** – Understanding how shared resources can support teamwork and collaborative tasks.
