## 🕊️ About the Activity

This activity focuses on applying presentation design principles in creating a promotional poster. It explores how visual elements can be organized and presented to communicate information clearly while maintaining an engaging and visually appealing design.

## 🎨 Activity Output

**Promotional Poster**

The output is a promotional poster designed using presentation design principles to establish a clear visual hierarchy, organize information, and create a cohesive visual presentation.

## ✧ Design Principles Applied

- **Visual Hierarchy** – Organizing elements to guide the viewer's attention toward the most important information.
- **Contrast** – Creating visual distinction between elements to improve readability and emphasis.
- **Alignment** – Arranging text and visual elements in an organized manner.
- **Proximity** – Grouping related information to make the content easier to understand.
- **Consistency** – Maintaining a cohesive appearance through the use of colors, fonts, and design elements.
- **Simplicity** – Avoiding unnecessary elements to keep the presentation clear and focused.

## 🪷 Reflection

This activity provided an opportunity to apply presentation design principles in creating a promotional poster. It emphasized the importance of organizing visual elements, choosing appropriate design components, and presenting information in a clear and engaging manner.
